# This document outlines the core values and direction of the game

## Included vehicles:
- A vehicle will be included in the game only if a full-size metal prototype moved under it's own power, with it's intended weapin physically mounted.

## Realism vs. fun:
- The game will try to be as realistic as possible by replicating real world conditions, but never at the cost of causing frustration to the player that does not add to the gameplay experience.

## Monetization and p2w:
- The game will never give paying players an advantage that is unobtainable without paying. The benefit of payment is cosmetics and progression speed, never gameplay advantages. A f2p player will always be able to achieve the same level of battle effectiveness as a paying player.
