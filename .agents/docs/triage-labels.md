# Triage labels

The five canonical triage roles are GitHub labels with the default strings: `needs-triage` (maintainer must evaluate), `needs-info` (waiting on the reporter), `ready-for-agent` (fully specified, an agent can take it), `ready-for-human` (needs the owner's hands or decision), `wontfix`. Category labels: `bug`, `enhancement`. Structure labels: `epic` (parent issue, tasks are its sub-issues) and `wayfinder:map` / `wayfinder:research` / `wayfinder:prototype` / `wayfinder:grilling` / `wayfinder:task`.

Every task carries one category label and one state label. An epic carries `epic` and no state label.
