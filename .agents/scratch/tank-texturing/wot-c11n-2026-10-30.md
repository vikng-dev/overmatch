# WoT tank texturing ("c11n"), from the wot session, 2026-10-30
Source: decompiled client items/components/c11n_constants.py + c11n_components.py (StranikS-Scan 1.46). R = read, I = inferred.

- Region model: 4 parts (chassis, hull, turret, gun) × up to 4 sub-regions = 16-bit ApplyArea mask. Each customization type is confined to a region subset (paint: most regions; camo: only the PRIMARY region of hull/turret/gun, chassis not camo'd; emblems/inscriptions/insignia/numbers: specific sub-regions). [R]
- Base: PBR texture set per part (albedo, normal, gloss, metallic), not trim sheets, not one tank atlas. Defaults gloss 0.509, metallic 0.23. [R/I]
- Paint: flat override per region: colour + gloss + metallic + colour group; a nation's base look = a default paint. Not a texture. [R]
- Camo: shared tiling pattern recoloured by a palette (≤5 colours), per-part tiling/scale/rotation, own camo UV set (or UV0), region-masked; it also modulates gloss/metallic and normal (surface finish, not a sticker); seasonal variants. [R]
- Decals: UV-placed stickers on emblem sub-regions (emblems, inscriptions, kill marks, numbers), plus projected decals (≤9, ≤3 per area) with gloss/emission. [R]
- Wear, grime, edges: no runtime layer; baked into the base part textures (albedo/AO + gloss/metallic). Paint/camo override gloss/metallic. [I]
- Non-metal parts (rope, logs, canvas, grilles, exhaust): outside the camo regions, keep their own authored material; styles can restyle them via nonTankMaterials. [R]
- LOD/cost: camo normal applies only up to LOD 1; base textures per tank, camo/decal/insignia are shared library assets (memory paid once); everything composites in ONE material, not extra passes. [R/I]
